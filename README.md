# Telecontact Leads — demand generation prototype

> « Nous transformons les personnes qui cherchent une entreprise sur Telecontact en demandes commerciales qualifiées, puis nous les mettons en relation avec les professionnels capables d’y répondre. »

A complete, self-contained, interactive prototype of the Telecontact WhatsApp demand-generation business:

**Telecontact fiche → WhatsApp button → bot qualification → structured demand → explainable matching → simulated WhatsApp distribution → company workspace → analytics.**

Everything runs in the browser. There are no external services, credentials or real WhatsApp messages. All data is fictional and clearly labelled as demo data.

## Run it

```bash
npm install
npm run dev        # http://localhost:5173
```

```bash
npm test           # 30 tests: customer journey scenarios A–J, matching, distribution, analytics, seed integrity
npm run build      # type-check + production build (static files in dist/)
```

Node 20+ recommended. The first load generates the demo dataset (about 1 s) and stores it in `localStorage`, so data survives refreshes.

## Five-minute demo script

1. **Telecontact (visiteur)** → open **SpaceFix — Casablanca** → *Contacter sur WhatsApp*.
2. The simulated WhatsApp opens with the pre-filled message. Press ➤.
3. Choose **Prix** → **OK** (consent) → type a name → **Confirmer ce numéro** → type
   `Je cherche un climatiseur 18000 BTU pour mon bureau` (the product, spec and details are extracted) → **2** → **Casablanca**.
4. The demand is registered. Click **Voir la demande dans l’admin**.
5. On the demand, SpaceFix (not subscribed) is recommended first as a **free opportunity**; Casa Clim and ElectroPro are explained alternatives. Click **Envoyer la demande**.
6. **Espace entreprise → SpaceFix**: the demand and its WhatsApp notification have arrived. Mark *Client contacté*; the admin sees the demand as *Prise en charge*.
7. Run the journey again on SpaceFix (use *Nouveau client* in the simulator tools). Its free opportunity is used, so the demand goes automatically to subscribed alternatives (Casa Clim, ElectroPro), and the matching panel explains why SpaceFix was skipped.
8. **Vue d’ensemble**: every metric has moved.

The simulator also has tools to replay a duplicate event, force a delivery failure, simulate the customer leaving for 45 minutes, and switch to a new simulated customer. Try **Non** at the consent step, an invalid phone number, or typing text when buttons are expected.

**Réinitialiser** (top bar) restores the original dataset.

## Repository layout

```
src/core/          business logic (no React, no browser APIs)
  conversation/    state machine + bot copy (FR/AR)
  ai/              interpreter port, rule-based extractor, validator
  matching/        explainable rules-based matching
  analytics/       metrics computed from records
  services/app.ts  application service: the single entry point (UI today, webhook later)
  store/           repository port + in-memory/localStorage adapter
  transport/       messaging port + simulated WhatsApp
  seed/            fictional dataset generated by replaying traffic through the engine
  simulation/      scripted customer (seed + tests)
src/ui/            React interface (directory, WhatsApp simulator, admin, company workspace)
tests/             vitest suites
```
